IndonesianEnglish

2. The special number 11–19

Indonesian uses belas for numbers 11–19.

SebelasEleven
Dua belasTwelve
Tiga belasThirteen
Empat belasFourteen
3. When do we use “se”?

Satu means one. Se- is a shortened form used in certain words:

  • Sebelas = eleven
  • Seratus = one hundred
  • Seribu = one thousand
See? Indonesian can be tricky! 😜
